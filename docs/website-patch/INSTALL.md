# חבילת הטמעה לאתר — לידים חיים, פיקסל מטא ונגישות

> הוכן 30.07.2026. כל קובץ כאן מוכן להעתקה לתוך `website/`. אין שלב build.

## 1. חיבור הטופס לקרן — `netlify/functions/lead.js`

**מה זה עושה:** מבקר ממלא טופס באתר → הפונקציה מעבירה את הליד ל-webhook של המערכת → קרן מתקשרת תוך פחות מדקה. במקביל נשלח אירוע Lead ל-Meta מהשרת (מדויק יותר מהדפדפן, לא נחסם ע"י חוסמי פרסומות).

**למה דרך פונקציית שרת ולא ישירות מהדפדפן:** נקודת הקצה של הלידים מאומתת עם `x-webhook-secret`. סוד כזה בקוד של הדפדפן = כל אחד יכול להזריק לידים מזויפים למערכת. הפונקציה רצה בצד השרת ושומרת אותו סגור.

### התקנה

1. העתק את `netlify/functions/lead.js` לתוך `website/netlify/functions/lead.js`.
2. ב-Netlify → Site configuration → Environment variables, הוסף:

   | משתנה | ערך |
   |---|---|
   | `API_BASE` | `https://ai-sales-agent-production-9736.up.railway.app` |
   | `LEAD_WEBHOOK_SECRET` | אותו ערך כמו במערכת (מתוך `.env`) |
   | `META_PIXEL_ID` | מזהה הפיקסל (אופציונלי) |
   | `META_CAPI_TOKEN` | טוקן Conversions API (אופציונלי) |

3. ב-`assets/site.js`, שנה את היעד של ה-fetch משורה 56 — במקום `fetch('/', {...})` צריך לשלוח **גם** ל-Netlify Forms (שמירה) **וגם** לפונקציה (שיחה). הקוד המדויק ב-`site.js.patch.md`.
4. פרוס ובדוק: מלא את הטופס עם המספר שלך. אמור לצלצל תוך פחות מדקה.

**נקודה משפטית:** הפונקציה שומרת `consent_source` ו-`consent_given_at` על כל ליד — זו ההוכחה שהליד ביקש שיחזרו אליו, וזה מה שמכשיר שיחה יוצאת לפי תיקון 40 לחוק התקשורת. אל תסיר את זה.

## 2. פיקסל מטא — `meta-pixel-snippet.html`

להדביק לפני `</head>` **בשני** עמודי השפה (`index.html` ו-`he/index.html`). ההערות בקובץ מסבירות מה לשנות.

חשוב: אירוע ה-Lead נשלח **גם** מהדפדפן וגם מהשרת עם אותו `event_id` — Meta מזהה שזה אותו אירוע ולא סופר פעמיים. זה הסטנדרט היום כי חוסמי פרסומות מפילים חלק מאירועי הדפדפן.

## 3. נגישות — `accessibility-patch.md`

רשימת התיקונים הקונקרטיים לאתר + קובץ CSS להוספה. תקן ישראלי 5568 ברמה AA.
