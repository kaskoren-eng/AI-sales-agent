# פלואו קליטת לקוח — ClickScales / KEREN

> טיוטת עבודה, 30.07.2026. המטרה: מהחתימה ועד סוכנת חיה תוך **5 ימי עסקים**.

## שלב 0 — לפני החתימה (יום המכירה)

- שיחת דמו: הלקוח ממלא את הטופס באתר ומקבל שיחה מקרן תוך 60 שניות — הדמו מוכר את עצמו.
- הצעת מחיר נשלחת באותו יום (ראה תבנית).
- חתימה על הסכם + DPA, תשלום דמי הקמה בקישור SUMIT.

## שלב 1 — שאלון אפיון (יום 1)

נשלח מיד אחרי התשלום. בלי שאלון מלא — הלו"ז לא מתחיל לרוץ (כתוב בהסכם).

**על העסק:**
1. שם העסק, תחום, אתר, אזור פעילות
2. מה אתם מוכרים ולמי? (2-3 משפטים במילים שלכם)
3. מה הופך ליד ל"שווה פגישה"? (קריטריוני qualification — תקציב מינימלי, אזור, סוג צורך)
4. מה פוסל ליד מיידית?
5. 3 ההתנגדויות הנפוצות ומה אתם עונים עליהן
6. מחירים — מה מותר לקרן להגיד? (ברירת מחדל: כלום — "נעבור על זה בפגישה")

**תפעול:**
7. מקורות הלידים (טפסים, קמפיינים, אתר) + גישה לחיבור
8. יומן לפגישות (Google Calendar — שיתוף הרשאה) + משכי פגישה + שעות זמינות
9. CRM קיים (Monday / Airtable / אחר) + גישה
10. שעות פעילות לשיחות (ברירת מחדל: 08:00–21:00, א'-ה')
11. לאן שולחים סיכומי שיחה והתראות (וואטסאפ/אימייל של מי)

**קול וסגנון:**
12. איך קוראים לסוכנת אצלכם? (ברירת מחדל: קרן)
13. טון: רשמי / חברי / אנרגטי
14. משפט פתיחה מועדף (נציע ניסוח, כולל הודעת הקלטה וגילוי AI — לא ניתן להסרה)

## שלב 2 — הקמה (ימים 2-3, אצלנו)

- [ ] יצירת tenant + הגדרות (voice_engine, שעות שקט, מגבלת הוצאה יומית)
- [ ] מספר טלפון ייעודי + חיבור SIP
- [ ] בניית פרומפט מותאם מתוך השאלון + בדיקות רגרסיה
- [ ] חיבור יומן (הרשאות DWD) + בדיקת קביעת פגישה
- [ ] חיבור CRM + מיפוי סטטוסים
- [ ] חיבור מקורות לידים (webhook / Meta Lead Ads / טופס אתר)
- [ ] הגדרת תבניות וואטסאפ ואימייל (אישור + תזכורות)

## שלב 3 — בדיקות עם הלקוח (יום 4)

- שיחת סימולציה: הלקוח מדבר עם הסוכנת שלו (סימולטור/שיחה אמיתית)
- ליד בדיקה מקצה לקצה: טופס → שיחה → פגישה ביומן → אישורים → CRM
- סבב תיקוני ניסוח אחד (מרוכז — לא טפטוף)
- **אישור Go-Live בכתב מהלקוח**

## שלב 4 — עלייה לאוויר (יום 5)

- הפניית לידים אמיתיים לסוכנת
- ניטור מוגבר 48 שעות ראשונות: האזנה לכל השיחות
- הודעה יזומה ללקוח בסוף היום הראשון: כמה שיחות, כמה פגישות, הקלטה לדוגמה

## שלב 5 — חודש ראשון (שימור)

- שבוע 1: צ'ק-אין יומי קצר בוואטסאפ
- שבועות 2-4: צ'ק-אין שבועי + האזנה ל-20 שיחות מדוגמות ושיפורי פרומפט
- סוף חודש: דוח ביצועים (שיחות, שיעור מענה, פגישות שנקבעו, no-shows) + שיחת סיכום

**טריגרי נטישה לטיפול מיידי:** ירידה חדה בלידים מופנים · הלקוח לא עונה לצ'ק-אין · תלונה על שיחה — האזנה + חזרה ללקוח באותו יום.
